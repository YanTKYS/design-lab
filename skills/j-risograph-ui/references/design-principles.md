# 二色刷り：守る規則・変えてよい点・避ける誤用

出典：design-lab の11番目の比較デザイン `j-risograph`（J案。比較サイト本体の CSS / JS と、採用前の独立した3画面の試作）。ここには、別の業務へ移すのに必要な核だけをまとめた。色の値は [../assets/tokens.css](../assets/tokens.css) を正とする。

## 着想と説明のしかた

- リソグラフ（孔版の二色刷り）の「版ごとに1色のインキを刷り重ねる」「版が少しずれる」「網点で濃淡を作る」という**刷り方の考え方**を、画面の役割分担に翻訳した。
- 説明するときは「リソグラフの二色刷りに着想した独自のデザイン（仮称：二色刷り、J案）」とする。特定の印刷所・製品・作品の再現、公式のデザインシステムとは言わない。
- 実在の印刷物・ポスターの図柄は取り込まない。網点・版ずれは CSS の基本図形で作る。

## どの部品を使うか

業務にない部品は作らない。迷ったら使わない。

| 対象の画面 | 使う | 使わない |
| --- | --- | --- |
| 一覧（台帳・受付簿） | 版ずれの大見出しと件数、丸い検索欄と状態の札、点線罫の表、選んだ行の直後の詳細 | — |
| 一覧の件数が数件だけ | 札と点線罫のリスト（表にしなくてよい） | 並べ替え、件数の大見出し |
| 入力（申込・記録） | 左に章名（網点の下線）、右に入力欄（2列。狭い幅で1列）、確認事項の網点の地と青い枠の箱 | — |
| 既に集計がある画面 | 上下の青い罫の間の指標、青の縦棒にピンクのずれ、件数と割合の表 | — |
| 集計がない画面 | 状態の札の件数・見出しの件数（文字） | 指標の帯・棒グラフを新たに足すこと |
| 業務用の高密度な画面（長時間・大量の行） | 罫・札・フォーカス・エラーの形だけ | 大見出しの版ずれ・網点の帯（飾りの量を減らす） |

## 必ず守る規則

| 規則 | 内容 |
| --- | --- |
| 2つの版 | 地は生成りの紙（`--jr-paper`）。文字・数値・罫・操作・状態・エラーは**青の版**（`--jr-blue`・`--jr-ink`・`--jr-muted`）。**ピンクの版**（`--jr-pink`・`--jr-pink-soft`）は、版ずれ・網点・ずれた影・波線の下線・選択の地・「必須」の地だけ。ピンクを消しても意味が失われないこと。 |
| 大見出しの版ずれ | 画面名などの大見出しだけ、青の極太の文字に、右下へ数 px ずれたピンクを重ねる（`text-shadow: var(--jr-misreg)`）。本文・ラベル・数値の表には使わない。文字を複製する場合は `aria-hidden` にし、読み上げを1回にする。 |
| 網点 | 大見出しの上の余白の帯（右上で薄れて消える）、選んだ行の地、章名の下線、確認事項の地だけ。**文字・数値・入力欄・フォーカスの枠の下に濃い網点を敷かない**（選んだ行の淡い網点は例外で、文字のコントラストを計算で確かめる）。飾りの要素は `aria-hidden`、背景なら読み上げられない。 |
| 罫 | 区画の上下・表の見出しは青の実線（2〜3px）。行・章の区切りは青の点線（`--jr-dot-rule`）。点線は飾りで、入力欄などの境界には使わない。 |
| 操作の階層 | 主操作は青の塗り・丸い形・紙の色の文字に、ピンクのずれた影（`--jr-shadow`）。副操作は青の枠。クリア・戻るは青の太字にピンクの波線の下線。影は飾りで、ない場合（強制カラー）も操作と分かる形にする。 |
| 状態 | 記号（○ ◐ △ ● × など）と文字の組。色の違いで状態を示さない。 |
| 選択 | 絞り込みの札は青の塗り＋✓＋紙の色の文字（＋ピンクの影）。選んだ行は淡い網点の地＋**左の青い帯**＋**「表示中」の反転札**。網点やピンクの影だけで選択を示さない（強制カラーでは背景と影が消えるため、文字の札を必ず置く）。 |
| 詳細 | 選んだ行の**直後**の行に開く（表の外の別の場所に出さない）。紙の色の箱に青の枠とピンクのずれた影。開閉ボタンに `aria-expanded`。開いたら詳細の見出しへ、閉じたら開閉ボタンへフォーカス。 |
| フォーカス | `outline: var(--jr-focus-ring)`、`outline-offset: var(--jr-focus-offset)`、`box-shadow: var(--jr-focus-halo)`。見えない `input` を使う札では、見た目の側（`input:focus-visible + span`）に同じ枠を出す。選択の塗り・ピンクの影と形を変える。 |
| エラー | 上部の一覧：二重罫の枠（`--jr-double`）に、反転札「エラー」＋「入力エラーが n 件あります」、項目名のボタンで欄へ。欄：ラベルの下に反転札「エラー」と理由・直し方、入力欄は二重罫の太枠（`--jr-double-field`）、`aria-invalid` とエラー文への `aria-describedby`。**エラーにピンクを使わない。** |
| 「必須」「任意」 | 「必須」は淡いピンクの地に青の文字、「任意」は枠だけ。文字で区別する（地の色だけに頼らない）。 |
| 数値とグラフ | 指標・件数は青の極太の数字。棒は青にピンクのずれた縁。棒の長さは隣の数値・割合と同じ尺度で、件数を棒の上か隣に文字で添える。棒・網点は `aria-hidden`、数値は文字で1回だけ読ませる。0件の値は一覧へのリンクにしない。 |
| 狭い幅 | 目安 760px 未満で、表は行ごとに縦へ積む（番号・状態を上、操作を右上）。列見出しは「並べ替え」の札の列に変え、並べ替えの操作を2組にしない。章は章名を上に、入力欄を1列に。大見出しを小さくし、網点の帯も低く・狭くする。主操作は全幅。ページ全体を横にはみ出させない。 |
| 部品の境界と補助文字 | 入力欄の枠は青（`--jr-blue`、入力欄の地で 8:1）。補助文字は `--jr-muted`（どの地でも 4.5:1 以上）、例示文字は `--jr-placeholder`。 |

## 変えてよい点

- **飾りの量**：網点の帯・版ずれ・ずれた影は、業務の性格に合わせて減らしてよい（長時間使う業務画面では大見出しの版ずれだけにする、など）。2つの版の役割分担・選択とエラーの形は残す。
- **大見出しの大きさ**：原本は 60px（狭い幅 38px）。画面の情報量に合わせて小さくしてよい。
- **表の列と詳細の中身**：業務の識別子（番号）→ 名前 → 区分 → 日付 → 状態の順を基本に、業務に合わせて選ぶ。
- **入力欄の列数**：2列が基本。項目が少なければ1列でよい。
- **丸い形**：札・ボタン・検索欄の丸（`--jr-pill`）は、対象アプリの部品の形に合わせて角丸を小さくしてよい。
- **状態の記号**：業務の状態に合わせて選ぶ。記号と文字は必ず組にする。
- **幅の切り替え**：画面全体なら `@media`、部品の領域で切り替えるなら `@container`。

## 避ける誤用

- ピンクで状態・エラー・必須・リンクの違いを示す（ピンクの文字、ピンクの枠のエラー、ピンクだけの選択）。
- ピンクの文字で本文を書く（紙の上で 2.6:1 で読めない）。
- 網点を文字・数値・入力欄・グラフの下に濃く敷く、画面全体に敷く。
- 版ずれを本文・ラベル・表の数字に使う。文字を複製した版ずれを読み上げさせる。
- 業務にない KPI・グラフ・表、意味のない網点の円を、見た目のために足す。
- 狭い幅で、列見出しの並べ替えと、別のセレクトの並べ替えを両方置く。
- 描き直しのたびに絞り込みの札（ラジオ）や行を作り直し、操作した部品のフォーカスを失わせる。
- design-lab の CSS・HTML・JS（比較サイト専用の `main.js`、`data-action` の規約、状態モデル、URL の規約）を持ち込む。
- 対象アプリのデータ・検索・検証・保存・URL・ルーティングを、見た目の都合で変える。
- 外部のフォント・CDN・API を追加する。

## 確認の観点

- ピンクを取り除いた状態（強制カラー、グレースケール、印刷）で、選択・状態・エラー・リンク・数値が分かるか。
- 淡い網点の上（選んだ行）の文字・補助文字のコントラスト。
- 大見出しの版ずれ・網点の帯が、件数・操作・入力欄と重ならないか（1280px・中間の幅・375px）。
- 狭い幅で、表を縦に積んだときの読み順、並べ替えの札が1組か、詳細が選んだ行の直後か。
- 長い日本語（備品名・団体名・同意文）の折り返し。
- 矢印キー・Tab の移動、絞り込み・並べ替え・開閉・エラー後のフォーカス、IME の変換中の検索。

## 原本から変えた値

| トークン | 原本（j-risograph.css） | Skill | 理由 |
| --- | --- | --- | --- |
| `--jr-muted` | `#4c5a8c` | `#48558a` | 原本は淡いピンクの地（`--jr-pink-soft`）で 4.44:1。Skill の値は紙 6.2:1、入力欄 7.0:1、淡いピンク 4.75:1 |
| `--jr-placeholder`（新設） | 例示文字に `#737ca3` | `#5c6894` | 原本の値は入力欄の地で 4.0:1。Skill の値は 5.35:1 |
| `--jr-misreg`（新設） | 大見出しの版ずれを `::before` に `content: attr(data-text) / ''` で複製 | `text-shadow` | 文字を複製しないので、読み上げが重ならず、代替テキストの書き方に対応しないブラウザでも二重に読まれない。ピンクは文字の後ろに出るので見た目は同じ |

そのほかの主な組み合わせ（計算値）：本文 `--jr-ink` は紙 9.2:1・入力欄 10.5:1・淡いピンク 7.1:1、見出し・操作の `--jr-blue` は紙 7.2:1、青の塗りの上の紙の色 7.2:1、フォーカスの枠（`--jr-ink`）は紙 9.2:1。ピンク（`--jr-pink`）は紙の上で 2.6:1 なので、文字や意味のある線には使わない。
