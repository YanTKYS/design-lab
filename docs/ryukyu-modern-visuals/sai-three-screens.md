## 一覧から引き継ぐ規則

| 役割 | 3画面での使い方 |
| --- | --- |
| 現在地と操作 | 藍のシステム名帯、深緑の画面名、右端の自作模様を一覧から引き継ぐ。画面の切替は比較サイト側が担い、各モックでは画面内の移動だけを示す。藍の塗りは主操作や現在の選択、藍の輪郭は副操作、下線は該当欄や一覧への移動。 |
| 面と境界 | 黄金の左縁が付いた砂色の面には、一覧の検索条件、フォームの進行状況、集計の条件を置く。藍の横罫から記録が始まり、淡い緑の面と深緑の縁が関連する項目を束ねる。一覧では行の詳細、フォームでは項目群、集計では処理完了のまとまりに使う。 |
| 色の意味 | 赤瓦色は模様内に限定。エラーは深紅と「エラー」・三角・太枠で示す。集計の藍は受付総数と系列、黄金は処理待ちの目印、緑は処理完了。却下は集計済みの区分として灰褐色で表し、各色には状態名・件数・割合を添える。 |
| 文字と密度 | 日本語ゴシック、本文16px、数値は桁幅をそろえる。大見出しの下は章見出し20〜23px、項目名16px、補足13〜14pxを目安にする。入力・ボタンは角丸4px、高さ44px以上。外余白は1280pxで52px、375pxで16px。長い項目名・自由記述・同意文は折り返す。 |

藍型の染め分けや石積みが面を区切る景観を参照した。図形とUI上の役割は本プロジェクトの創作。今回の2画面には一覧の実装にある幾何模様をそのまま用い、入力欄とグラフは無地にした。[文化的な着想と出典](README.md#現行の試作から変えたところ)・[初期コンセプト](../ryukyu-modern-concept.md)

## 入力から確認・完了まで

- **入力**では、氏名・ふりがな、メール・電話、種別・希望日を隣り合わせにし、長文と同意は全幅を使う。電話番号は「任意」と入力例を併記する。画像は共通の正常例のうち任意の電話を空欄にしたもの。375pxでは項目を文書順に積み、補足がどの欄に属するかを追えるようにする。
- **「確認へ」でエラーがあるとき**は入力段階にとどまる。図はふりがなをカタカナにし、メールの「@」を「#」に置き換えたときの共通モデルの2件。サマリーにフォーカスを移し、項目名から各欄へ戻れるようにする。修正中は値を維持し、サマリーと欄直下の理由を一緒に更新する。[エラー時の部分モック](sai-errors.png)
- **確認**では8項目を入力順に表示し、空の電話は「入力なし」、同意は「同意する」と記す。各行の「修正」は対応する入力欄へ、「入力に戻る」は編集の先頭へ戻す。「申請する」で完了へ進む。[確認画面の部分モック](sai-confirm.png)
- **完了**では手順の「3 完了」を強調し、「申請が完了しました」を見出しにする。比較用の試作であること、送信・保存されないことを明記する。受付番号の発行は想定しない。[フォームモデル](../../site/assets/js/form.js)・[入力例](../../site/assets/js/data.js)・[利用仕様](../usage.md#入力フォーム)

## 集計値と一覧への導線

両幅とも集計条件は **令和8年度（4月〜）・すべての担当課**。基準日は2026年10月12日。画像の数字と表示順は `buildDashboardModel({ period: 'fy', dept: '' })` の戻り値を使用した。受付71件、処理待ち19件、処理完了52件、完了率73.2%。月別の棒は4〜10月を同一目盛で描き、各棒の上に実数を載せる。状態の帯は受付総数を分母とし、直下の凡例に件数と割合を示す。種別別の横棒は最多の13件を基準とし、右端の割合は受付総数を分母とする。[共通集計モデル](../../site/assets/js/dashboard.js)・[集計仕様](../usage.md#ダッシュボードの集計)

- 条件の変更は指標と全内訳に反映し、「リセット」で既定の期間・全担当課に戻す。受付件数・処理待ち・処理完了の「一覧を見る」、状態名、種別名からは、期間・担当課と選んだ状態や種別を一覧へ引き継ぎ、検索語を空にする。完了率と月別の棒は読み取り専用。
- 375pxでは指標を2列、グラフを1列に積む。種別の比較は項目名・件数・割合に絞り、棒に使っていた横幅を長い日本語名に渡す。受付0件では件数は0、分母を持たない割合は「—」とする。

## 判断してから試作する点

本文比較では、3画面とも黄金の縁→砂色の面→藍の罫から作業を読み始められる。フォームでは淡緑の項目見出しが一覧の表頭に最も近い。一方、ダッシュボードの藍の受付件数面はボタンと取り違えやすい。画像では移動できる箇所だけに下線を付けた。誤認が残れば、数値面を白に戻して「一覧を見る」の下線を残す。

375pxではフォーム末尾の主操作、集計末尾の種別内訳まで縦移動が長い。原寸画像で「任意の電話を飛ばして確認へ進む」「処理待ち件数から該当一覧への入口を見つける」を試し、文字を探した場所を記録する。静止画で確認できたのは表示内容・改行・配置まで。フォーカス移動、IME、読み上げとタッチ操作は次の実働試作で確かめる。[UI品質レビュー観点](../ui-quality-review.md)
