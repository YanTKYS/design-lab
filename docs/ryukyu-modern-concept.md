# Ryukyu Modern（琉球モダン）設計案

**提案は、処理状態を索引にした申請台帳。** 職員が「どの状態に何件あるか」を見て対象を選び、申請者と受付番号を照合し、その場で処理期限を読む。第9の比較候補として、まず申請一覧のこの一連の操作を試す。

## 着想と使いどころ

| 参照したこと | この画面への取り入れ方（独自の設計判断） |
| --- | --- |
| 竹富島の集落には白砂の道、琉球石灰岩の石積み、赤瓦や茅葺きの家屋がある。[竹富町教育委員会の解説](https://www.town.taketomi.lg.jp/soshiki/kyoikuiinkai/syakaibunka/1761628946/) | 石積みが通路と敷地を分ける様子から、条件を選ぶ面と記録を読む面の境界を引く。石灰岩を想起する淡色を索引の地に、白を台帳の地に使う。赤瓦色は台帳の始まりを示す見出しの短い罫に一度だけ置く。 |
| 紅型には藍を用いる藍型があり、染め重ねにも複数の技法がある。[沖縄県立図書館「基礎知識」](https://www.library.pref.okinawa.jp/archive/contents/cat38/knowledge.html) | 藍一色でも濃淡と輪郭で区別できる点を手がかりに、操作の強さを塗り、輪郭、文字の順で表す。フォーカスや選択の意味は形と文言でも読めるようにする。 |

地域ごとに異なる景観と工芸のうち、ここでは二つの例を参照した。名称と色値は現代の業務画面のための仮称・候補値。面と罫線は基本図形で構成し、写真・型紙・既存の図案は取り込まない。

## 申請一覧

### 1280px の比較枠

通常は全71件を受付日の新しい順に表示する。下図は「道路」で検索し、処理状態を「審査中」に切り替えた場面。左の件数は検索語と引継ぎ条件に一致した内訳、右の件数は処理状態も適用した結果。データと並び順は既存の共通モデルを使う。[申請データ](../site/assets/js/data.js)・[検索と件数の定義](../site/assets/js/query.js)

```text
さくら野市　申請管理システム　　　申請一覧　新規申請　ダッシュボード　設定
申請一覧
キーワード［道路　　　　　　　　　　　］［検索］
──────────────────────────────────────────
処理状態          │ 絞り込み中　「道路」・審査中　　71件中 1件　［検索条件をクリア］
  すべて     12件 │ 受付番号     申請者                申請種別        受付日 ↓    処理状態
  受付済      0件 │ 2026-01041  株式会社さくら野建設  道路占用許可申請  2026/10/08  審査中
● 審査中      1件 │ ［詳細］
  補正依頼    1件 │
  承認済      8件 │
  却下        2件 │
```

- **移動と検索。** 自治体名・システム名、共通ナビの順に置く。現在地は太字・下線と `aria-current` で示す。「新規申請」はナビから開く。見出し直下に「キーワード」と、検索できる項目（受付番号・申請者名・ふりがな・申請種別・担当課）を表示する。確定文字の入力で結果を更新し、Enter と「検索」でも確定できる。IME変換中は入力と結果を保持する。
- **状態の索引。** 幅176pxを目安に、単一選択のラジオ群を縦に並べる。全6択は同じ順でゼロ件も残し、件数の桁を右でそろえる。選択丸と太字で現在の状態を示す。Tabでグループに入り、矢印で選ぶと台帳だけが更新される。
- **結果と詳細。** 残りの幅を5列の表に使う。各列見出しで並べ替えでき、対象列に矢印と `aria-sort` を付ける。「詳細」は受付番号セルの2段目のボタン。読み上げ名に番号を含める。開くと直後の全列にまたがる行に「申請詳細（受付番号）」と項目・値の組を表示する。一度に開くのは1件。詳細には一覧の5項目に加えて担当課、受付方法、処理期限、備考（空なら「なし」）を出す。
- **開閉と復帰。** 開いた詳細見出しにフォーカスを置く。「詳細を閉じる」または詳細内のEscで元の番号のボタンに戻す。条件、並び、読んでいた行の位置を保つ。共有URLから直接開き、該当行が絞り込み範囲外なら、結果見出しの直後に対象番号と「現在の条件の対象外」を添えて詳細を表示し、閉じたら結果見出しに戻す。

### 375px の比較枠

```text

申請一覧
キーワード［道路　　　　　］［検索］
処理状態　［審査中（1件）　▾］
絞り込み中　「道路」・審査中
71件中 1件　［検索条件をクリア］
並べ替え　［受付日 ▾］ ［降順］
───────────────────
受付番号 2026-01041　　　審査中
申請者　 株式会社さくら野建設
申請種別 道路占用許可申請
受付日　 2026/10/08　　 ［詳細］
```

比較枠が幅960px未満なら状態索引を件数付きの標準セレクトに変えて表の上に置く。600px未満ではナビを開閉式にし、表を1件ずつのラベル付きリストに切り替える。両方の幅で同じ5項目と詳細を読める。狭い幅の並べ替えは5項目の選択と昇順／降順の切替で行う。長い法人名・種別は折り返し、操作は次の行に送る。詳細は選んだ記録の末尾に開く。ナビと詳細の開閉状態はボタンの文言と `aria-expanded` で伝え、幅変更後も対象番号と選択条件を引き継ぐ。

### 件数と条件の扱い

| 場面 | 表示と操作 |
| --- | --- |
| 条件なし | 「全71件」。状態索引は「すべて」。結果が変わる操作でもフォーカスは操作元に保ち、件数だけを穏やかに読み上げる。 |
| 絞り込み中 | 件数の隣に適用中の検索語・状態を明記。「検索条件をクリア」で両方を戻し、キーワード欄にフォーカスを戻す。ダッシュボード由来の条件は別行に「引き継いだ条件」と内容・専用の解除ボタンを出す。その場合、件数の分母は引継ぎ条件内の総数。 |
| 0件 | 件数の位置は保ち、行の位置に「一致する申請はありません」と表示。検索語・状態があれば「検索条件をクリア」、引継ぎ条件があればその解除が使える。0件は通常の検索結果として扱う。 |

## 視覚と操作の規則

| 用途 | 試作で使う候補 |
| --- | --- |
| 文字と数字 | 端末内の「BIZ UDPゴシック」→「ヒラギノ角ゴシック」→「メイリオ」→ sans-serif。見出し24px・太字、本文と入力16px・行高1.5、列名と補助14px。件数・日付・受付番号は等幅数字を指定し、同じ桁位置を追えるようにする。 |
| 面・余白・境界 | 石灰岩色 `#F7F3E8`、記録面は白、本文は墨色 `#263238`。項目内4〜8px、列間16px、領域間24px、狭い枠の外余白16px。台帳行は高さ56px以上で内容に応じて伸びる。横罫で申請を区切る。入力とボタンは角丸4px、入力境界は `#64716F` の実線。 |
| 主操作と副操作 | 「検索」「確認へ」は琉球藍 `#204B60` の塗り＋白い動詞ラベル。「詳細」「閉じる」は白地・藍の輪郭と文字。「クリア」は下線付きの文字ボタン。押下時は内側の縁を太くし、狭い枠の操作領域は高さ44px以上を目安にする。 |
| 状態・通知 | 状態バッジには台帳の正式な状態名を常に出す。承認済・成功は海緑 `#237A76` とチェック、補正依頼・注意は黄褐色 `#765000` と三角。却下は結果を示す文字ラベル。入力エラーには深紅 `#9C2034` の太枠と「エラー」・理由・直し方。将来の危険操作には「削除する」など結果を明示した動詞と確認を用いる。 |
| フォーカス | 白い2pxの間隔を挟み、外側に墨色3pxの実線を描く。選択丸・下線との同時表示を保つ。プログラムで移した先にも枠を出す。強制カラーではシステム色の輪郭を残す。 |

**藍と赤瓦の使い分け。** 白文字とのコントラスト比は藍 `#204B60` が9.39:1、赤瓦 `#AC4D3A` が5.42:1（不透明なsRGB単色の相対輝度から算出）。赤瓦の主ボタンは淡い背景で暖色の操作を見つけやすくする狙いがあるが、入力エラーや危険操作にも赤系が現れるため、形と文言の識別に負担がかかる。試作は明暗差の大きい藍を採り、赤瓦色は見出しの罫に限る。実機のフォーカス境界、淡色背景、強制カラーでの見え方は比較時に確認する。

## DADS・Plain と何を比べるか

| 比較軸 | DADS（本サイトの実装） | Plain | 琉球モダン案 |
| --- | --- | --- | --- |
| 状態を選ぶ | 上部の検索条件パネルでセレクトを開く | 検索語と状態を文書順に指定 | PCでは全状態の件数を同時に読み、索引から選ぶ。代わりに表の横幅を176px程度使う |
| 詳細を照合する | 詳細ページへ移動し、一覧へ戻る | 表の上の詳細欄で読む | 選んだ記録と次の記録の間で読む。照合中も元行が見える一方、展開すると後続行が下がる |
| 密度と狭幅 | ゆったりしたセルと罫線付き表。狭幅は表内を横移動 | 小さいセル余白と標準部品の表。狭幅は表内を横移動 | PCは列位置をそろえ、375pxは全項目を縦に読む。横移動を省く代わりに複数件の同時比較に使える行数が減る |

既存2案の比較根拠は、[デザイン比較ガイド](comparison-guide.md)、[DADSの一覧](../site/assets/js/designs/dads.js)、[Plainの一覧](../site/assets/js/designs/plain.js)。

## 他画面への展開

- **入力フォーム**では一列の読み順を優先する。各ラベルに「必須」「任意」を添え、形式と入力例は欄の前に置く。「確認へ」でエラーがあれば件数と該当欄リンクをまとめた見出しに移動し、欄の直後にも理由と修正例を示す。確認画面は項目名と値の組で読み返し、「修正」で値を保って元の欄に戻る。
- **ダッシュボード**では期間・担当課・基準日を指標の前に置く。受付件数を母数に、処理待ち・完了を件数、完了率を割合で併記する。母数0の割合は「—」。状態名・並び順は索引と共通にし、棒に名称・値・単位を直接添え、凡例と数表でも読めるようにする。件数から同条件の一覧へ移る。[共通の集計仕様](usage.md#ダッシュボードの集計)

## 一覧だけの試作で確かめること

[デザイン選定ガイド](design-selection.md)の職員・反復作業・端末幅を前提に、[UI品質レビュー観点](ui-quality-review.md)のシナリオA・Cを使う。琉球モダン／DADS／Plainで同じデータ、初期順、枠の高さ・幅、文字倍率をそろえ、各案を1280pxと375pxで同じ順に操作する。

| 操作 | 観察・記録すること |
| --- | --- |
| 全71件から「道路」→「審査中」→受付番号2026-01041の詳細 | 12件から1件へ絞れたか。キーボードだけで処理期限（2026/10/29）を読み、閉じて元行と条件へ戻れたか。迷った位置と操作数を記録する。 |
| 申請者で並べ替え、昇降順を切り替える。375pxと文字200%でも同じ記録を読む | 初期表示で完全に読める行数、長い法人名の折返し、隣の申請との境界、隠れた項目・横移動の有無を記録する。索引が表の幅を圧迫する場合は切替幅を見直す。 |
| IMEで「道路」を変換し、「架空ゼロ」に変更して0件から復帰する | 変換中の文字・フォーカス・件数通知、0件の理由と解除先が読めるか。集計から来た場合も検索条件と引継ぎ条件を別々に解除できるか。 |
| Tab、拡大、強制カラー、読み上げで状態選択と詳細開閉を繰り返す | 選択と現在のフォーカスを別々に指せるか。名称・件数・展開状態、復帰先、隣接色の実測値を記録する。赤瓦の罫を外した状態でも操作の意味が通るかを見る。 |

現時点で確認したのは既存データの件数と指定色の計算値まで。職員の操作時間、支援技術での挙動、地域の利用者が受け取る印象は未検証。レビューでは「どの状態で何をしたか・観察結果・直すか」を記録し、地域表現への感想は操作の記録と分ける。
