# 研究資産の索引

13デザインを同じデータ・条件で比較するには[公開サイト](https://yantkys.github.io/design-lab/)を使います。登録済みの各デザインの操作と画面写真は[デザイン比較ガイド](comparison-guide.md)にあります。

GitHub Pages の公開対象は `site/` です。以下の「試作」はブラウザで操作でき、「設計資料」「画面写真」「検証記録」はGitHubで閲覧できます。資料中の「現行」「未登録」は、それぞれの作成時点での位置づけです。

## H′・J・K・Lの試作を見比べる

[4案×3画面の比較ハブ](https://yantkys.github.io/design-lab/experiments/hjkl/)から、各案の申請一覧・入力フォーム・ダッシュボードを開けます。12画面は採用前の操作を確かめるための独立試作です。左右比較や条件のURL共有は、冒頭の公開サイトで試せます。

- 原案の画面構成を横断して比べるには、[4案×3画面の画像一覧](cross-screen-comparison/README.md)と[ダッシュボードの原案比較](dashboard-comparison/README.md)を参照してください。
- 試作の操作・ソース・画面写真は、[申請一覧](list-prototypes/README.md)・[フォーム](form-comparison/README.md)・[ダッシュボード](dashboard-prototypes/README.md)にまとまっています。

## Skill作成時の適用見本と検証記録

[固定の適用見本](../examples/)には、5つの独自デザインを別の業務に適用した当時のHTML・素材・画面写真が残っています。各見本の `VERIFICATION.md` に確認手順と結果があります。[糸の交点の業務メモ](../examples/okinawa-thread-memo/VERIFICATION.md)・[折本の部屋予約](../examples/h-prime-room-booking/VERIFICATION.md)・[二色刷りの備品貸出](../examples/j-risograph-equipment-lending/VERIFICATION.md)・[汀線の照会進捗](../examples/k-shoreline-inquiry-tracker/VERIFICATION.md)・[標示盤の窓口呼び出し](../examples/l-signage-counter-queue/VERIFICATION.md)

現在配布しているSkillの正本・導入手順は [design-skills](https://github.com/YanTKYS/design-skills) にあります。個別の移転先は[旧skillsパスの案内](../skills/README.md)、design-labの変更履歴は[CHANGELOG](../CHANGELOG.md)を参照してください。
