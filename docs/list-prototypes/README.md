# 申請一覧の操作できる試作（H′・J・K・L）

4案の申請一覧を、それぞれ独立した試作にした。データは比較サイトと共通の架空の71件、検索・処理状態の絞り込み・並べ替え・件数は共通の `query.js` をそのまま使う。検索条件や選択はページを開いている間だけ保ち、申請の更新や送信はしない。4案とも継続して比較する。

**全件への到達**　J・K・L は表に71件すべてを並べる。H′ は8面ずつ右から左へ並べ、「← 次の8件」「前の8件 →」で9面目（65〜71件目）まで送れる。並べ替えは、J・K・L は列見出し、H′ は「並べ替え」の項目と昇順／降順の切替で行う。
