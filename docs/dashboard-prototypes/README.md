# ダッシュボードの操作できる試作（H′・J・K・L）

## 共通の操作

- 既定は令和8年度（4月〜）・すべての担当課・基準日 2026年10月12日で、受付71件・処理待ち19件・処理完了52件・処理完了率73.2%。
- 対象期間か担当課を変えると、指標・月別・処理状態別・申請種別別がそろって更新される。見出しの下に対象の期間と担当課を文字で出し、集計した結果を読み上げる。
- 「既定に戻す」で両方の条件を戻し、フォーカスは対象期間に移る。既定のときは押せない状態（`aria-disabled`）で示す。
- 該当が0件のときは、割合を「—」で示し、0除算の NaN や誤った 100% を出さない（共通モデルの値のまま）。種別の表には「この条件に該当する申請はありません。」と出す。
- 処理状態別・申請種別別の棒は、どちらも受付総数に対する構成比で描き、隣の割合の数字と同じ尺度にする（共通モデルの割合の値をそのまま使う）。
- 処理状態は色だけに頼らない。H′・J・K は記号（○ 受付済・◐ 審査中・△ 補正依頼・● 承認済・× 却下）を添え、L は「処理待ち／処理完了」の区分を文字で示す。
- 状態とイベントは小さな共通の制御（[dashboard-poc.js](../../site/experiments/shared/dashboard-poc.js)）にまとめ、見た目は各案の `*-dash-view.js` が持つ。設定画面は対象外で、ナビでは無効の表示にしている。

## 案ごとの扱い

- **H′ 折本**　指標は右端の受付件数から左へ読む（「指標は右端から ←」）。月別は左から右へ時系列（「月の順 →」）で、向きの切り替わりを文字で示す。375px では指標を受付件数から縦に積む。
- **J 二色刷り**　網点は最初の指標の右上に置き、上の罫で切る。数値と説明文には掛からない位置にし、文字はつねに網点より上に描く。ピンクは版ずれ・網点の飾りに限り、数値と棒は青で示す。
- **K 汀線**　各月の値は、点・縦の線・点の真上の件数で示す。点の高さは件数に比例し、0件の月は点・縦の線・面を基準線に置く。線（破線）と面は推移の目安として淡く添え、単調3次補間で描くので、隣り合う2か月の値の範囲から上にも下にもはみ出さない（月の途中に山や谷を作らない）。グラフの下に「点が各月の件数です。線と面は推移の目安で、月の途中の値を示すものではありません。」と注記する。記号的な飾りは足していない。
- **L 標示盤**　ドット文字は上段の4指標だけに使う。1桁の値は消灯の桁で盤面の幅をそろえ、0 で埋めない（「08件」と読めないようにする）。月別と種別別は「1目盛り＝1件」の点灯で、目盛りの数は最大値を5の倍数に切り上げる。375px でも種別名の長さにかかわらず目盛りの列幅を確保する。右端に実数を出すので、1目盛りの差も数字で確かめられる。処理状態の表は、処理待ちの区分を上段の処理待ち件数と同じ琥珀で結ぶ。

## 原案からの変更

- 4案とも、集計条件の欄に「既定に戻す」を足した。見出しの下に、対象の期間と担当課を文字で出す。
- 4案とも、表の件数・割合は右にそろえ、375px でも「18.3%」が折り返さないようにした。
- H′・J は、月別の件数を棒の真上に置いた。原案と同じ配置で、棒の高さは1つの固定の高さに対する比で描く。
- H′・J・K の処理状態に記号を添えた。
- J は、網点を説明文から外した（原案では説明文の末尾に重なっていた）。
- K は、曲線を単調補間の破線にした。各月の点に縦の線を足し、注記を足した。点の高さは底上げせず件数に比例させた。
- L は、処理完了率の「%」をドット文字にせず単位として添えた。

## 確かめたこと

- ユニットテスト（[dashboard-pocs.test.mjs](../../tests/unit/dashboard-pocs.test.mjs)）
  - 4つの条件で、4案の指標・月別・処理状態・種別の数値が共通の集計と一致する。
  - 既定の値が71／19／52／73.2%である。
  - 0件でも NaN・Infinity・100% を出さず、割合を「—」で示す。
  - 一覧へのリンクがない。
  - K の曲線の制御点が、隣り合う月の値の範囲に収まる。0件の月は基準線に置く。
  - H′・J・K の種別の棒の長さが割合と一致する（13件／71件で18.3%、8件／8件で100%）。
- E2E（[hjkl-dashboards.spec.mjs](../../tests/e2e/hjkl-dashboards.spec.mjs)）　4案それぞれで次を確かめた。
  - 既定の値。
  - 対象期間をキーボード（↓）で変え、Tab で担当課へ進んで市民課にする。全体が8／2／6／75.0%に更新され、読み上げとタイトルも変わる。
  - URL とストレージは変わらない。
  - Tab と Enter で既定に戻し、フォーカスが対象期間に移る。
  - 375px で横にはみ出さない。L は種別の目盛りが幅を持ち、先頭行（13件）が13目盛り点灯する。
